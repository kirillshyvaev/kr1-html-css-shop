# ShopProject — учебный интернет-магазин

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина ShopProject:
главная страница, каталог с фильтрами, карточка товара, страница оформления заявки и контакты.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров с блоком фильтров;
- `product.html` — карточка товара с таблицей характеристик и отзывами;
- `order.html` — страница оформления заявки;
- `contacts.html` — контактная информация и частые вопросы;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `sitemap.xml` — простая карта сайта;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git.

## Использование Flexbox и Grid

В проекте используются:
- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:
- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `section` — универсальный раздел страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара (модификаторы `--featured`, `--discount`);
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `filters-form` — форма фильтров;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `button` — кнопка (модификаторы `--primary`, `--secondary`, `--disabled`);
- `info-box` — дополнительный информационный блок;
- `success-message` — сообщение об успешной отправке;
- `site-footer` — подвал сайта.

## Позиционирование

- `position: sticky` — шапка сайта `site-header` прилипает к верху страницы;
- `position: relative` — карточка товара `product-card` как контейнер для бейджа;
- `position: absolute` — бейджи «Хит», «Новинка», «Скидка» (`product-card__badge`);
- `position: fixed` — кнопка «Наверх» (`to-top`);
- `z-index` — шапка и кнопка «Наверх» располагаются поверх содержимого (переменные `--z-header`, `--z-to-top`).

## Самостоятельные доработки

- страница товара с изображением, бейджем, ценой, таблицей характеристик и блоком отзывов;
- отдельная страница заявки с выбором товара, количества и способа получения;
- блок частых вопросов на странице контактов (`details`/`summary`);
- бейджи на карточках и модификаторы `product-card--featured`, `--new`, `--discount`;
- sticky-шапка и фиксированная кнопка «Наверх»;
- хлебные крошки с промежуточным уровнем (Главная / Каталог / Товар);
- активный пункт меню (`site-nav__link--active`, `aria-current="page"`);
- улучшенная доступность формы: подсказка через `aria-describedby`, подсветка ошибок через `aria-invalid`.
